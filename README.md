# bn.dict Developer Workspace

This repository contains the complete source files, dataset curation pipeline, emoji mapping rules, and binary compiler for developing, updating, and building **`bn.dict`** (the Bengali vocabulary and emoji dictionary) for **OsthirKeyboard / NHSCustomKeyboard**.

---

## 🚀 Key Highlights & Capabilities

- **Massive Bengali Vocabulary**: Expanded from an initial 115 words to **501,234 validated Bengali words** (18.6 MB source, ~4.04 MB compiled binary).
- **Comprehensive Morphological Coverage**: Contains rich inflected forms (বিভক্তি ও প্রত্যয়যুক্ত রূপ: `-গুলো`, `-দের`, `-টি`, `-এর`, `-তে`, `-সহ`, `-ও`) ensuring smooth keyboard autocomplete for everyday Bengali writing.
- **Strict Orthographic & Phonotactic Validation**: Strips legacy font artifacts (ZWJ/ZWNJ), rejects truncated or corrupt tokens, and canonically recomposes Unicode nuktas (`ড়`, `ঢ়`, `য়`) to match native Android keyboard drivers.
- **Bilingual & Phonetic Emoji Suggestions**: Over **1,394 keywords** and **1,279 shortcuts** supporting English (`love`), Banglish (`valobasa`), and Bengali script (`ভালবাসা`) to target emojis (`❤️`).
- **Zero-Dependency Native Compiler**: High-performance Python-based Minimal DFA/DAWG compiler (`libcdict` Format v1). Compiles all 501k words in **~20 seconds** without OCaml, opam, or dune.
- **Ultra-Fast Lookups**: Compiles into a memory-efficient Directed Acyclic Word Graph (DAWG) with 4-bit compressed frequency tables enabling **microsecond** lookups on mobile devices.

## 🧹 Linguistic & Orthographic Validation Pipeline

Raw web and OCR datasets contain encoding quirks, legacy Bijoy converter artifacts, and incomplete words. The generation pipeline ([`scripts/generate_max_bangla_combined.py`](file:///e:/Development/AndroidApp/bn.dict/scripts/generate_max_bangla_combined.py)) enforces rigorous cleaning rules:

1. **Bengali Nukta Canonical Recomposition**:
   - Standard Unicode NFC leaves nukta letters decomposed (`\u09a1\u09bc` for ড+়, `\u09a2\u09bc` for ঢ+়, `\u09af\u09bc` for য+়) because of Unicode CompositionExclusions.
   - The pipeline recomposes these into canonical precomposed characters:
     - `\u09a1\u09bc` $\to$ **`ড়`** (`\u09dc`)
     - `\u09a2\u09bc` $\to$ **`ঢ়`** (`\u09dd`)
     - `\u09af\u09bc` $\to$ **`য়`** (`\u09df`)
   - This ensures exact byte matching when mobile keyboard drivers send single-character keycodes.

2. **Legacy Zero-Width Cleanup**:
   - Strips stray zero-width non-joiners (`\u200C`) and joiners (`\u200D`) injected by older font converters (e.g., `'অতিথ\u200c\u200cি'` $\to$ `'অতিথি'`, `'অক\u200c্ষয়'` $\to$ `'অক্ষয়'`).

3. **Phonotactic Constraints**:
   - **No Illegal Initial Signs**: Words cannot start with dependent vowel signs (kārs: `া ি ী ু ূ ৃ ে ৈ ো ৌ`), viramas (`্`), or diacritics (`ঁ ং ঃ ়`).
   - **No Trailing Virama**: Rejects words ending with hasanta (`্`), which eliminated ~1,947 cut-off/truncated OCR words (e.g. `অণুবীক্ষণযন্ত্`).
   - **No Consecutive Kārs or Viramas**: Eliminates typographical glitches like `াা` or `্্`.
   - **Length Filtering**: $1 \le \text{length} \le 20$ characters, rejecting accidental glued multi-word sentences.
   - **Pure Digits Excluded**: Pure numeric digit strings (`০-৯`) are excluded in favor of spelled-out number words.

4. **Corrupt Dump Rejection**:
   - Un-normalized dump files lacking viramas entirely (e.g., `জনয`, `মধযে`, `হযে`) are rejected; standard forms (`জন্য`, `মধ্যে`, `হয়ে`) are verified and preserved.

## 🛠️ Build, Test & Verification Workflow

### 1. Re-generate Vocabulary (Optional):
To re-run the aggregation and validation pipeline:
```powershell
python scripts/generate_max_bangla_combined.py
```

### 2. Compile `bn.dict`:
Run via PowerShell or Python:
```powershell
.\build.ps1
# or
python scripts/build.py
```
This produces `output/bn.dict` (~4.04 MB) containing both the `main:` vocabulary and `emoji:` shortcuts.

### 3. Run Verification Tests:
Verify dictionary integrity, vocabulary lookups, and emoji shortcuts:
```powershell
python scripts/verify_bn_dict.py
```
All test suites check:
- **Baseline words**: `আমি`, `তুমি`, `ভালোবাসা`, `বাংলাদেশ`, `ধন্যবাদ`, `মা`, `বাবা`
- **Standard vocabulary**: `অংশীদার`, `বাগ্দান`, `সুদক্ষ`, `অম্লীকরণ`, `সঠিকতা`
- **Root words**: `অপনীত`, `অংশক`, `অঞ্জলি`
- **Inflections**: `অঙ্গপ্রতিষ্ঠানগুলো`, `অঙ্গসংগঠনগুলোর`, `অঙ্গপ্রতিষ্ঠানে`, `উপজেলার`, `ছাত্রীরাও`
- **Nukta words**: `হয়ে`, `হয়েছে`, `বাড়ি`, `দৃঢ়`, `বাঙালি`
- **Number words**: `একশ`, `হাজার`, `কোটি`
- **Negative tests**: `মধযে` (False), `জনয` (False), `হযে` (False), `অবাকশব্দ` (False)
- **Emoji shortcuts**: 100+ tests covering English, Banglish, and Bengali triggers

### 4. Deploy to Android App:
Deploy directly into the keyboard app's asset folder:
```powershell
python scripts/build.py --deploy ../NHSCustomKeyboard/assets/dictionaries/
```

## 📱 Mobile Runtime Performance

- **Format**: `libcdict` Format Version 1 (compatible with OsthirKeyboard / AnySoftKeyboard cdict engine).
- **RAM Footprint**: `bn.dict` is memory-mapped (`mmap`) by Android's native runtime; only traversed trie nodes are paged into memory.
- **Binary Size**: ~4.04 MB for 501,234 words + 1,394 emoji keywords.
- **Lookup Latency**: Microsecond-level prefix and exact lookups during live user typing.
